# SmartHub — сайт академии робототехники и дронов

Продакшн: **https://smarthub-kz.com**

Лендинг на трёх языках, приём заявок в базу и админ-панель для менеджеров.
Заявки автоматически создаются сделками в Битрикс24.

## Структура

```
index.html            главная (русская версия, исходник переводов)
en/ kz/               сгенерированные языковые версии
privacy.html          политика конфиденциальности, три языка
admin.html            панель заявок (закрыта паролем)

api/lead.js           приём заявки: валидация, антиспам, запись, отправка в CRM
api/leads.js          список и удаление заявок для панели
api/login.js          вход в панель

lib/store.js          PostgreSQL, сессии администратора
lib/bitrix.js         создание сделки в воронке Битрикс24

tools/build-langs.py  сборка en/ и kz/ из index.html + sitemap.xml
assets/               логотипы, иконки, изображения секций
```

## Переменные окружения

Список и пояснения — в `.env.example`. Реальные значения задаются
в Vercel: Project → Settings → Environment Variables.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да | PostgreSQL для заявок |
| `ADMIN_PASSWORD` | да | вход в `/admin` |
| `ADMIN_SECRET` | да | подпись сессии, соль для хеша IP |
| `BITRIX_WEBHOOK_URL` | нет | входящий вебхук CRM |
| `BITRIX_CATEGORY_ID` | нет | воронка, по умолчанию `1` (Smart Hub) |
| `BITRIX_STAGE_ID` | нет | стадия, по умолчанию `C1:NEW` |

Без `DATABASE_URL` заявки живут в памяти процесса и пропадают
при перезапуске — только для локальной разработки.

## Локальный запуск

```bash
npm install
cp .env.example .env.local     # заполнить значения
vercel dev
```

## Языковые версии

Русский текст правится в `index.html`, переводы лежат в словаре `I18N`
там же. После правок пересобрать:

```bash
python tools/build-langs.py
```

Скрипт создаёт `en/index.html`, `kz/index.html` и обновляет `sitemap.xml`.
Правки напрямую в `en/` и `kz/` затрутся при следующей сборке.

## Деплой

```bash
vercel --prod
```

Подробности, включая подключение домена и базы — в `DEPLOY.md`.
